### Proposed Steps

1. **Confirm the route remains publicly reachable without middleware changes** (Phase 1)

2. **Add the dynamic, uncached health endpoint** (Phase 2)

Exact complete file contents:

import { NextResponse } from "next/server";

export const dynamic = "force-dynamic";

export function GET() {
  return NextResponse.json(
    { status: "ok" },
    { headers: { "Cache-Control": "no-store" } },
  );
}

`force-dynamic` is preferred to `revalidate = 0` because it explicitly documents that the health route must be evaluated by the running server rather than become eligible for build-time static output. `Cache-Control: no-store` separately protects against browser, CDN, and proxy reuse of a stale healthy response.
   *Files:* `app/api/health/route.ts`
   *Dependencies:* Confirm the route remains publicly reachable without middleware changes
3. **Verify the production health-check contract** (Phase 3)
   Build and run the application in production mode, then request `GET /api/health`. Confirm HTTP 200, an `application/json` content type, body exactly `{"status":"ok"}`, and `Cache-Control: no-store`. Production-mode verification is important because static-route behavior is a build-time concern that development-server testing does not reliably exercise.
